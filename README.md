# Insurance Content Growth

面向中国保险从业者的自媒体内容生产与合规预审 Skill。

## 功能

- 生成保险自媒体周内容计划
- 生成短视频口播稿和提词稿
- 将同一主题改写为视频号、抖音、小红书和微信内容
- 生成评论区和私信首轮回复
- 标记产品事实、收益、理赔和案例等待核验内容
- 提供面向未来软件化的技术设计和用户 Q&A

## 安装

将本仓库目录复制到 Codex 技能目录：

```text
~/.codex/skills/insurance-content-growth/
```

Windows 通常对应：

```text
C:\Users\你的用户名\.codex\skills\insurance-content-growth\
```

安装后重启 Codex，或在新任务中明确提到保险自媒体内容生产、口播稿、内容合规预审等需求。

## 使用示例

```text
请帮我制定一周保险自媒体内容计划。
我的目标客户是 28-40 岁的年轻家庭，主要发布在视频号。
请同时生成每天的口播稿、标题、封面文案、拍摄提示和合规风险提示。
```

## 重要边界

本 Skill 不替代保险公司、保险中介机构或专业合规人员的审核，不自动发布内容，不凭空生成产品条款、收益、理赔结论或成交承诺。涉及具体产品时，应提供最新版批准材料，并在发布前完成人工审核。
