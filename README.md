# 保小创｜保险短视频生产包

> 面向中国保险代理人和团队的场景化内容助手。
>
> 把“我想讲保险”变成“客户在这个生活瞬间会想听什么”，再交给剪映数字人和豆包完成视频。

**安装标识：** `insurance-content-growth`<br>
**产品名称：** 保小创｜保险短视频生产包
**适用对象：** 保险代理人、经纪人、团队主管、机构自媒体运营者

<div align="center">

**场景化口播稿 · 豆包 15 秒切片 · 剪映合成方案 · 合规预审**

</div>

## 为什么是“保小创”

保险内容的难点通常不是没有知识，而是很难把知识放进客户真正经历的生活里。

保小创会先找到一个具体场景：夜里孩子发烧、父母体检、房贷扣款、第一次发工资、整理旧保单……再把场景中的犹豫和风险缺口，转成自然、可读、可剪辑的短视频方案。

它不替你承诺“爆款”或“成交”，而是帮助你稳定地产出可信、能共鸣、方便制作的内容。

## 一次产出什么

每次生成的是一套可执行的**视频生产包**，而不是一个孤立的口播稿：

| 模块 | 产出 |
| --- | --- |
| 场景策略 | 目标人群、生活场景、核心担忧、内容目标 |
| 数字人口播 | 剪映可粘贴稿，含停顿、语气、镜头和结构标注 |
| 豆包切片 | 按每日额度生成最多 5 条独立的 15 秒竖屏提示词 |
| 时间轴 | 每条切片对应哪句口播、何时进入、何时回到数字人 |
| 剪辑方案 | 字幕、转场、音乐、音效、封面、CTA 和 AI 标识 |
| 风险预审 | 待核验事实、证据需求、发布前人工审核清单 |

## 推荐工作流

```text
保小创
  ↓  场景化脚本 + 数字人口播 + 豆包提示词 + 时间轴
豆包
  ↓  生成最多 5 条 15 秒情境切片
剪映专业版
  ↓  数字人播报 + 导入切片 + 字幕/音乐/封面/标识
人工复核
  ↓  检查条款、事实、画面暗示和平台要求
发布
```

## 安装

将仓库目录复制到 Codex 技能目录：

```text
~/.codex/skills/insurance-content-growth/
```

Windows 通常是：

```text
C:\Users\你的用户名\.codex\skills\insurance-content-growth\
```

安装后重启 Codex，或在新任务中直接描述保险自媒体内容需求。Skill 的技术标识保持英文，方便安装和自动识别；在界面中显示为“保小创｜保险短视频生产包”。

## 第一次怎么用

直接复制下面的请求，再替换方括号内容：

```text
请用“保小创”帮我生成一套保险短视频生产包。

目标人群：[例如：28-40 岁、有孩子的年轻家庭]
生活场景：[例如：孩子半夜发烧，家长一边陪诊一边担心费用]
想讲的主题：[例如：家庭医疗保障应该先看什么]
发布平台：[抖音/视频号/小红书]
目标时长：[例如：60 秒]
我每天可用的豆包 15 秒切片额度：[5 条]
我的身份和风格：[例如：本地寿险代理人，专业但像朋友聊天]
可用的官方资料：[粘贴产品条款、公司审核稿或官方链接；没有就只讲通用知识]

请输出：场景化口播稿、剪映数字人设置、豆包切片提示词、时间轴、剪辑方案、封面文案、CTA 和合规检查。
```

如果暂时没有产品资料，也可以先让它做通用风险教育；涉及具体产品、数字、等待期、续保、理赔或收益时，必须补充经批准的材料。

## 需要配合的工具

| 工具 | 负责什么 | 是否由本 Skill 自动操作 |
| --- | --- | --- |
| Codex + 本 Skill | 选题、场景、口播、提示词、时间轴、检查清单 | 是内容生成，不自动发布 |
| 豆包 | 生成 15 秒情境化 B-roll 切片 | 否，用户手动生成 |
| 剪映专业版 | 数字人、配音、字幕、合成、音乐、导出 | 否，用户手动操作 |
| 官方条款/公司审核资料 | 核验产品事实与销售口径 | 用户提供 |
| 人工审核 | 确认最终视频可发布 | 必须保留 |

本 Skill 不调用剪映或豆包，不生成 MP4，不自动登录平台，不自动发布内容。

## 使用优势

- **更容易共鸣：** 从客户的生活瞬间开始，而不是从险种名词开始。
- **更低制作门槛：** 不要求代理人出镜拍摄，数字人承担口播，豆包提供情境画面。
- **更省额度：** 按每天可用的豆包次数设计，默认最多规划 5 条，不鼓励无效试错。
- **更好剪辑：** 每条切片都绑定口播句子和时间点，导入剪映后按表执行。
- **更稳妥：** 把通用教育、产品事实、案例叙述和 AI 生成画面分开检查。
- **更可复用：** 同一主题可以继续改成视频号、抖音、小红书和私信回复。

## 建议的进阶配置

为了让产出越来越像你的账号，建议逐步补充：

1. **账号人设卡：** 从业年限、服务地区、擅长人群、禁用表达、常用语气。
2. **客户场景库：** 按年龄、家庭结构、职业和人生阶段记录真实高频问题。
3. **合规资料库：** 公司审核口径、产品条款、官方 FAQ、可引用的公开资料及版本日期。
4. **数字人规范：** 固定形象、声音、语速、镜头比例、字幕风格和 AI 标识位置。
5. **复盘表：** 记录完播率、评论问题、私信关键词和人工审核退回原因，用于优化下一批选题。

## 重要边界

本 Skill 是内容生产和发布前预审助手，不是保险公司、保险中介、律师、财务顾问或监管机构。它不会凭空生成产品条款、收益、理赔结论、真实客户案例或成交承诺。

豆包生成的画面只用于表现情境和氛围，不能作为保险事实、理赔结果、医疗结论或产品收益的证明。发布前请以最新批准材料和机构审核意见为准，并按平台要求处理 AI 生成内容标识。
