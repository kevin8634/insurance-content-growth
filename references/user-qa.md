# User Q&A

## 能直接生成并发布视频吗？

第一版只生成内容和制作指导，不自动发布。最终内容需要人工确认和机构审核。

## 没有产品资料还能用吗？

可以生成一般保险科普、风险教育和沟通框架，但不能凭空生成具体产品的保费、收益、保障额度、理赔结论或条款解释。

## 为什么经常出现“待核验”？

数字、产品利益、期限、理赔结论、案例结果和监管结论都需要可追溯依据。补充最新版批准材料后，才能进入人工复核。

## 可以写得更有冲击力吗？

可以增强开头、场景和节奏，但不能使用虚假稀缺、恐吓、绝对承诺、夸大收益或隐瞒重要条件。

## 不想露脸怎么办？

可以输出旁白、图文卡片、手部演示或屏幕录制版本。使用数字人或声音克隆时，应遵守平台和机构披露要求。

## 能根据客户健康情况直接推荐产品吗？

不能。Skill 可以整理问题和沟通提纲，但不能替代资质、核保、适当性评估或机构审批。

## 如何开始？

准备账号定位、目标客户、主平台和 3-5 份已批准材料，先生成 7 天计划，连续使用四周，再根据发布量、有效咨询和审核耗时判断是否产品化。

## 如何判断是否值得付费？

看连续使用、节省写稿和剪辑时间、有效咨询和合规返工是否改善，不要只看生成次数或一次性好评。
