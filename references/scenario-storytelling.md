# 场景化共鸣脚本

保险内容的目标不是把术语讲得更完整，而是让目标人群在一个具体生活瞬间里认出自己，再愿意进一步了解风险和解决路径。

## 核心链路

每条口播优先使用以下链路：

1. **真实处境**：从一个可观察的生活动作开始，例如带孩子去医院、父母体检、房贷扣款、自由职业者停工或家庭整理账单。
2. **情绪张力**：描述当事人的犹豫、担心、侥幸、内疚或不知所措，但不靠灾难化语言制造恐慌。
3. **风险缺口**：指出这件事中真正需要想清楚的问题，只讲一个核心缺口。
4. **通俗解释**：用普通人能复述的语言解释概念，必要时区分保障对象、触发条件、额度和除外责任。
5. **下一步动作**：给出低门槛动作，例如做一张家庭保障清单、核对等待期、整理既有保单或预约一次需求沟通。

## 选场景的方法

优先选择同时满足以下条件的场景：

- 目标人群每月或每年都会遇到；
- 能在 3 秒内用一个动作或物件表现出来；
- 能自然引出一个保险问题；
- 不需要虚构客户姓名、医院结果、理赔金额或真实案例；
- 结尾可以落到一个具体而克制的行动。

推荐场景库：

| 人群 | 可用场景 | 适合讨论 |
| --- | --- | --- |
| 年轻家庭 | 夜里孩子发烧、家庭账单、备孕检查 | 医疗支出、家庭责任、保障优先级 |
| 中年家庭 | 父母体检、房贷扣款、夫妻讨论教育金 | 家庭收入依赖、父母责任、长期规划 |
| 个体经营者 | 店铺暂停营业、客户取消订单、整理流水 | 收入中断、经营与家庭风险隔离 |
| 初入职场 | 第一次发工资、租房、公司福利说明 | 基础保障、社保与商业保险边界 |
| 有既有保单的人 | 找不到保单、续期提醒、家庭成员问保障 | 保单整理、续保条件、保障缺口 |

## 口播结构模板

```text
场景钩子：当 [具体人群] 遇到 [具体生活瞬间]，很多人第一反应是 [常见想法]。
共鸣推进：真正让人犹豫的，往往不是要不要保障，而是 [具体担忧]。
核心解释：这件事建议先分清 [一个关键概念]，再核对 [一个关键条件]。
边界说明：具体能不能赔、能赔多少，要以 [合同/官方材料/实际审核] 为准。
低门槛 CTA：如果你愿意，可以先把 [一份材料/一张清单] 整理出来，再做一次针对性的核对。
```

## 场景化质检

- 开头是否出现了人、时间、地点或动作中的至少两项？
- 用户能否在脑中看到画面，而不是只听到概念？
- 是否把情绪落到了一个可验证的问题，而不是停留在焦虑？
- 是否只解释一个核心观点，避免一条视频塞入多个险种？
- 是否避免把虚构场景说成真实客户案例？
- 结尾是否给了一个不要求立即购买的下一步？

## 与豆包切片的关系

场景口播中的核心动作应优先转成豆包画面，例如“整理家庭账单”对应桌面整理和家庭讨论，“父母体检”对应陪同候诊的背影。切片只表现情境和情绪，不表现具体理赔结果、保单条款、收益数字或医院结论；事实仍由剪映数字人口播完成。
